# ASF Manobras — optional English

Portuguese is the default. English is activated only by a user choice and remembered on this origin. Browser language and geolocation are never used for automatic selection. Preference uses the same asf-language/asf-lang conventions as the ASF hub; browser localStorage is not shared between subdomains.

Reviewed coverage: visible fundamentals and maneuver instructions, bottom turn, complete four-step Cutback guide and common mistakes/dry-land exercise, off the lip, wave guidance, FAQs, checklist display labels, all eight rotating training focuses, countdown, footer legal-link labels and browser title. ASF brand names and universal surf terms remain unchanged. Shared network link names and third-party advertisements are not translated by this catalog.

The local generated i18n.js uses the tested hub engine pinned at bc474a6e47e1f87c2bc7bb7a6ba2ec91ae9f9dff, merged with translations-en.json. No translation API or runtime dependency on the hub is used. Portuguese content remains the canonical HTML and SEO structured data.

Do not translate M/st storage keys, change checkbox event handlers, modify XP values or redirect the canonical guide anchor #guia-cutback-completo. This change translates existing teaching content; it does not revise or independently validate surfing advice. Production verification must not award XP to a real user; XP interaction is tested in an isolated DOM.

Rebuild with the manual install-english workflow. Coverage and state-preservation tests must pass before index.html/i18n.js are committed. The broader hub, internal pages and other satellites remain separate rollout work.
